# דגל ישראל בתלת-ממד - Israeli Flag 3D (Ultra-High Graphics)

🌐 **קישור לאתר בלייב (Live Website):** [https://almog787.github.io/Playalmog/](https://almog787.github.io/Playalmog/)

---

אתר תלת-ממדי מרהיב המציג אך ורק את **דגל ישראל מתנוסס בגאווה** ברזולוציית 4K סופר-גבוהה וגרפיקה פוטוריאליסטית, עם סימולציית בד פיזיקלית מתקדמת (Cloth Physics), תאורה אטמוספרית דינמית וצלילי משב רוח עדינים.

---

### 🇮🇱 מאפיינים גרפיים ופיזיקליים:
1. **טקסטורת דגל 4K מדויקת**:
   - יחס רשמי מדויק 8:11 לפי חוק הדגל.
   - כחול מלכותי (Techelet Blue) ומגן דוד גיאומטרי מושלם.
   - מפת תבליט של אריגת בד (Fabric Micro-Weave Bump Map) המציגה את סיבי הבד והתפירה תחת האור.
2. **סימולציית פיזיקת בד (Verlet Integration Cloth Physics)**:
   - מארג חלקיקים תלת-ממדי (Mass-Spring Constraints).
   - כוחות אווירודינמיים, כבידה, משבי רוח ומערבולות היוצרים גלי בד טבעיים.
3. **עמוד תורן מתכתי יוקרתי**:
   - תורן כרום מוברש, חוד חנית וגולה מוזהבת בראש התורן (Golden Finial).
   - גלגלת, חבל מתוח וטבעות תפיסה מפליז.
   - מעמד אבן ירושלמית / גרניט יוקרתי.
4. **תאורה ואטמוספירה מתקדמת (Three.js Sky Shader)**:
   - ☀️ **שמש צהריים**: שמי תכלת ים-תיכוניים ושמש בהירה.
   - 🌅 **שקיעת זהב**: גווני כתום וסגול חמימים של שקיעה ישראלית.
   - 🌌 **לילה מלכותי**: זרקורי תאורה עוצמתיים המאירים את הדגל משני הצדדים.
   - 🌄 **זריחה צלולה**: שחר מואר ורך.
5. **בקרת מצלמה ואינטראקציה**:
   - סיבוב 360°, זום והטיה חופשיים (OrbitControls).
   - זוויות צילום מוכנות: מבט הירו מלכותי, תקריב מגן דוד, גלי הרוח ומבט פנורמי.
   - מצב הילוך איטי (Cinematic Slow-Motion).
   - שליטה על עוצמת הרוח והמשבים (2 עד 30 מ'/שנ').
   - אפשרות להסתרת הממשק לצפייה נקייה ומצב מסך מלא.
6. **צלילי רוח מבוססי Web Audio API**:
   - סאונד רוח ונפנוף בד ריאליסטי ללא תלות בקבצים חיצוניים.
